## 三个候选利基方向

### 方向A：听障儿童AI言语康复训练平台

| 维度 | 评分 | 说明 |
|------|------|------|
| 市场规模 | 3/5 | 中国听障儿童约20万，但家长付费意愿强，康复机构数千家 |
| 竞争强度 | 5/5 | 竞争极低——现有产品多为线下或简单App，无AI自适应方案 |
| 技术壁垒 | 5/5 | IRT+DTW+语音AI组合壁垒高，难以复制 |
| 变现速度 | 2/5 | 医疗/教育领域决策慢，需机构合作，周期6-12个月 |
| 技能匹配 | 5/5 | MVP已存在，完全匹配 |
| 兴趣匹配 | 5/5 | 核心项目，高度契合 |
| **总分** | **25/30** | |

### 方向B：外国人中文发音AI教练

| 维度 | 评分 | 说明 |
|------|------|------|
| 市场规模 | 4/5 | 全球中文学习者超2亿，发音纠正是刚需 |
| 竞争强度 | 2/5 | 竞争激烈——HelloChinese、Duolingo、Pleco等巨头林立 |
| 技术壁垒 | 4/5 | DTW发音评分有差异化，但大厂可快速复制 |
| 变现速度 | 4/5 | C端订阅模式，获客后可快速变现 |
| 技能匹配 | 4/5 | 语音技术可复用，需适配中文声调场景 |
| 兴趣匹配 | 3/5 | 有趣但非核心热情 |
| **总分** | **21/30** | |

### 方向C：言语治疗师AI辅助工具SaaS

| 维度 | 评分 | 说明 |
|------|------|------|
| 市场规模 | 3/5 | 中国言语治疗师约5万人，机构数千家 |

| **总分** | **22/30** | |

## 推荐利基陈述

> **为听障儿童康复机构及家庭，提供基于AI语音识别+IRT自适应算法的个性化言语康复训练系统，替代传统人工评估，实现发音精准评分与训练路径自动调整。**

**选择理由**：技术壁垒最高(5分)、竞争最低(5分)、技能完全匹配(5分)、现有MVP可直接验证。

**主理人注**: 考虑到学生+零预算约束，方向A变现速度慢（2/5）是主要风险。建议在推进过程中同时关注方向B和C作为快速变现的辅助路径。
