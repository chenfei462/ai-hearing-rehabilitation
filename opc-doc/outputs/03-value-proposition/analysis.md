# 阶段 03：价值主张设计

**产出者**: 价值主张设计师 言之
**日期**: 2026-09-15

---

## 目标客户画像

**主客户：听障儿童康复机构（B端）**
- 民办言语康复中心、特殊教育学校、公立医院康复科
- 决策者：机构负责人、教务主任、资深言语治疗师
- 规模：10-50名治疗师，50-200名在训儿童
- 预算特征：经费有限，依赖政府补贴+家长付费，对ROI敏感
- 技术现状：纸质量表+人工评估为主，信息化程度低

**次客户：听障儿童家长（C端）**
- 孩子2-8岁，人工耳蜗/助听器佩戴者
- 家长25-40岁，焦虑但积极参与康复
- 核心诉求：清晰了解孩子进步、在家也能练习

## Customer Pains

| # | 痛点 | 严重程度 | 当前替代方案 |
|---|------|---------|-------------|
| P1 | 人工评估主观性强，不同治疗师评分标准不一致 | 高 | 纸质量表、录音回听 |
| P2 | 评估效率低，每次15-30分钟 | 高 | 人工逐字评估 |
| P3 | 训练路径"一刀切"，无法动态调整 | 高 | 固定教材、经验判断 |
| P4 | 家庭训练缺监督，家长不知道练得对不对 | 中 | 家长录音发微信群 |
| P5 | 数据碎片化，散落在纸质/Excel/微信中 | 中 | 手工汇总 |
| P6 | 进步不可见，家长感受不到效果，续费意愿低 | 中 | 口头描述 |
| P7 | 治疗师培训成本高，新治疗师需1-2年 | 低 | 师徒带教 |

## Pain Relievers

| 痛点 | 产品缓解方案 | 实现机制 |
|------|-------------|---------|
| P1 人工评估主观 | AI发音评分引擎，音素级量化打分 | Fun-ASR + DTW对齐算法，输出0-100分 |
| P2 评估效率低 | 2秒内自动出评分报告 | 录音→ASR→评分→报告，端到端<2秒 |
| P3 训练路径一刀切 | IRT自适应算法自动调整难度 | 2PL模型，连续3次≥80%升级，<60%降级 |
| P4 家庭训练缺监督 | 家长端，录音即评 | 儿童在家录音→AI实时评分→家长看到结果 |
| P5 数据碎片化 | 统一数据平台，自动生成周报 | PostgreSQL + 定时任务生成PDF周报 |
| P6 进步不可见 | 可视化进步曲线+里程碑徽章 | 趋势图表+游戏化成就系统 |
| P7 治疗师培训成本 | AI评估结果作为"参考答案" | 新治疗师对照AI评分校准判断 |

## 价值主张陈述

> **为言语康复机构提供AI驱动的发音评估与自适应训练系统，用音素级量化评分替代人工主观评估，用IRT算法实现千人千面的训练路径，让每位治疗师的效率提升50%，让每个孩子的进步清晰可见。**

**一句话版本**：AI让每一次发音练习都有精准反馈，让每一个孩子的进步都有据可查。

## 竞品差异化

| 对比维度 | 聪听科技 | Lace AI | **本产品** |
|---------|---------|---------|----------|
| 核心定位 | 听力检测设备+软件 | 成人听力训练APP | **听障儿童言语康复训练** |
| 目标用户 | 医院（检测场景） | 成人C端 | **机构+家庭B+C** |
| 技术核心 | 纯音测听硬件 | 听觉训练游戏化 | **ASR音素评分+IRT自适应** |
| 评估能力 | 听力阈值检测 | 无发音评估 | **音素级发音评分** |
| 自适应能力 | 无 | 简单正确率调整 | **IRT 2PL数学模型** |
| B端价值 | 硬件销售 | 无B端 | **治疗师效率+数据管理+家长报告** |

**核心差异化**：唯一聚焦"发音评估+自适应训练"的产品，B+C双端形成闭环，IRT算法比竞品更精准。
