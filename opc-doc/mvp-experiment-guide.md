## 实验总览

### 三大假设验证

| 假设 | 验证目标 | 时间 | 资源 |
|------|---------|------|------|
| ① AI评估准确性 | Kappa≥0.7 | W1-W3 | 45小时 |
| ② 治疗师采用意愿 | ≥60%评分≥4分 | W2-W4 | 20小时 |
| ③ 家长付费意愿 | ≥20%愿意付费 | W3-W5 | 20小时 |

**总投入**: 85小时，零现金成本

## 假设①：AI评估准确性验证

### 目标
AI音素级评估与资深治疗师一致性≥85%（Kappa≥0.7）

### 执行步骤

#### W1：联系机构、收集样本

**任务1：联系康复机构**
- 目标：2-3家机构
- 方式：电话/微信/实地拜访
- 话术：
  > "您好，我们是AI言语康复团队，正在做一项研究，想邀请贵机构参与。我们提供免费的AI评估工具，帮助治疗师提升效率。请问可以安排10分钟电话沟通吗？"

**任务2：收集发音样本**
- 目标：10-15名儿童
- 要求：
  - 年龄：3-8岁
  - 听力损失：中度及以上
  - 佩戴助听器/人工耳蜗
- 样本内容：
  - 单音节词（10个）
  - 双音节词（10个）
  - 简单句子（5个）

**任务3：招募治疗师**
- 目标：2-3名资深治疗师
- 要求：
  - 从业3年以上
  - 愿意参与盲测评估
- 报酬：免费使用AI系统1年

#### W2-W3：双盲评估

**评估流程**：
1. **AI评估**：自动分析所有样本，生成评分
2. **治疗师评估**：治疗师独立评分，不知AI结果
3. **对比分析**：计算Kappa值和准确率

**数据记录表**：

| 样本ID | 音素 | AI评分 | 治疗师1评分 | 治疗师2评分 | 一致性 |
|--------|------|--------|-------------|-------------|--------|
| | | | | | |

**成功标准**：
- Kappa≥0.7（中等一致性以上）
- 音素错误检测准确率≥85%

### 降级方案
如果无法联系到机构：
- 使用公开数据集AISHELL-3模拟
- 邀请言语治疗专业学生参与评估

## 假设②：治疗师采用意愿验证

### 目标
≥60%治疗师体验后评分≥4分（5分制使用意愿）

### 执行步骤

#### W2：招募治疗师

**招募渠道**：
- 康复机构社群
- 高校言语治疗专业
- 校友/实习关系
- 小红书/知乎专业用户

**招募话术**：
> "我们开发了一款AI言语康复辅助工具，想邀请您体验并反馈。只需30分钟演示+7天试用，即可获得免费使用权限。请问有兴趣吗？"

**目标**：8-10名治疗师

#### W3：演示+试用

**演示内容（30分钟）**：
1. 产品功能介绍（10分钟）
2. 实际操作演示（10分钟）
3. 答疑和试用说明（10分钟）

**试用安排（7天）**：
- 开通试用账号
- 每天使用产品评估2-3个案例
- 记录使用感受

**反馈收集**：
- 使用意愿评分（1-5分）
- 功能满意度评分
- 改进建议

#### W4：访谈+分析

**结构化访谈（15分钟/人）**：
1. 整体使用体验如何？
2. 哪些功能最有用？
3. 哪些功能需要改进？
4. 是否愿意在工作中使用？为什么？
5. 能接受的价格范围？

**成功标准**：
- ≥60%治疗师"使用意愿"≥4分
- 收集具体改进建议

### 降级方案
如果招募困难：
- 通过校友关系定向邀请
- 降低目标人数到5-6人

## 假设③：家长付费意愿验证

### 目标
≥20%家长愿意为≤300元/月服务付费

### 执行步骤

#### W3：制作问卷

**问卷设计（10-15题）**：

1. **基本信息**
   - 孩子年龄
   - 听力损失程度
   - 康复训练时长

2. **痛点调研**
   - 目前康复训练的主要困难
   - 对现有服务的满意度

3. **价值感知**
   - AI评估功能的价值评分
   - 自适应训练的价值评分

4. **付费意愿**
   - 不同价格点的付费意愿（50/100/200/300元/月）
   - 愿意付费的原因
   - 不愿意付费的原因

5. **竞品对比**
   - 目前使用的康复产品
   - 对比本产品的优势

**问卷工具**：问卷星（免费版）

#### W4-W5：发放+分析

**发放渠道**：
- 家长社群
- 小红书
- 知乎
- 康复机构推荐

**发放数量**：50-100份

**数据分析**：
- 各价格点付费意愿比例
- 付费意愿影响因素
- 开放性建议汇总

**成功标准**：
- ≥20%家长选择300元/月档位表示"可能"或"一定"购买

### 降级方案
如果付费意愿低：
- 测试更低价格点（50-100元/月）
- 调整价值主张

## 决策框架

### 全部通过（3/3）
- **决策**：进入开发阶段
- **动作**：制定产品开发计划

### 部分通过（2/3）
- **决策**：调整后重验
- **动作**：针对未通过的假设调整方案

### 全部不通过（0-1/3）
- **决策**：考虑转向
- **动作**：重新评估利基定位

## 风险与应对

| 风险 | 应对策略 |
|------|---------|
| 机构拒绝合作 | 多联系几家，提供免费试用作为激励 |
| 治疗师招募困难 | 通过校友关系，提供免费使用1年作为报酬 |
| 家长问卷回收率低 | 在社群发放，提供小礼品激励 |
| 验证结果不理想 | 分析原因，调整方案后重验 |
