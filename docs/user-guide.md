# 用户使用指南

## 概述

AI 听觉康复助手是一款帮助人工耳蜗术后患者进行家庭听觉训练的移动 Web 应用。通过 AI 技术提供个性化的听觉训练、实时对话陪练和发音评估服务。

## 快速开始

### 1. 访问应用

在手机浏览器中打开应用地址。推荐使用 Chrome 或 Safari 最新版本。

### 2. 登录

1. 输入您的手机号码
2. 点击"获取验证码"
3. 输入收到的短信验证码
4. 点击"登录"

### 3. 首页功能

登录后，您将看到四个功能模块：

| 功能 | 说明 |
|------|------|
|   听觉训练 | 分级听力训练，从音节到噪声环境逐级提升 |
|   对话陪练 | AI 模拟真实场景对话，练习日常交流 |
|   发音反馈 | 录音发音，AI 逐音素评分并给出纠正建议 |
|   训练报告 | 查看训练进度、能力变化趋势 |

---

## 功能详解

### 听觉训练

**训练级别**（从易到难）：

1. **音节级** - 单个音节的辨别（如 ma, ba, da）
2. **词语级** - 双字词语的识别（如 妈妈, 你好）
3. **语句级** - 完整句子的理解
4. **噪声级** - 带背景噪声的句子识别

**操作步骤**：

1. 选择训练级别
2. 点击"开始训练"
3. 点击播放按钮听取音频
4. 选择您听到的内容（或输入文字）
5. 查看答题结果
6. 完成 10-20 道题后查看训练总结

**自适应机制**：
- 系统会根据您的答题情况自动调整题目难度
- 连续答对 → 题目变难
- 连续答错 → 题目变易
- 无需手动选择难度

### 对话陪练

**可用场景**：

| 场景 | 描述 |
|------|------|
|   餐厅点餐 | 模拟在餐厅点菜的对话 |
|   医院就诊 | 模拟看医生时的交流 |
|   超市购物 | 模拟在超市购物的对话 |
|   问路导航 | 模拟问路和指路的对话 |
|   电话通话 | 模拟打电话的场景 |

**操作步骤**：

1. 选择对话场景
2. 听取 AI 的开场白
3. 点击麦克风按钮说话
4. 等待 AI 回复
5. 继续对话直到场景结束

**提示**：
- 说话时请保持正常语速
- 如果没听清，可以点击"重听"
- 对话结束后会显示本次练习的评价

### 发音反馈

**操作步骤**：

1. 系统会显示需要练习的文字
2. 点击"播放示范"听标准发音
3. 点击麦克风按钮开始录音
4. 朗读显示的文字
5. 点击停止录音
6. 等待 AI 评分结果

**评分维度**：

| 维度 | 说明 |
|------|------|
| 准确度 | 声母、韵母、声调的发音是否正确 |
| 流利度 | 语速是否适中，是否有停顿 |
| 完整度 | 是否完整朗读了所有文字 |

**查看详细结果**：
- 音素级评分：每个音素的得分
- 纠正建议：针对错误发音的改进建议
- 对比播放：标准发音与您的发音对比

### 训练报告

**报告内容**：

1. **训练概览** - 总训练次数、总用时、平均正确率
2. **能力分布** - 各级别当前能力值（theta）
3. **正确率趋势** - 最近 30 天的正确率变化
4. **训练活动** - 每日训练热力图

## 常见问题

### Q: 听不到声音怎么办？

A: 请检查：
1. 手机是否静音
2. 浏览器是否允许播放音频
3. 音量是否调至合适大小
4. 如果使用助听器/人工耳蜗，请确保连接正常

### Q: 语音识别不准确怎么办？

A: 请尝试：
1. 在安静的环境中使用
2. 靠近手机麦克风说话
3. 保持正常语速，不要过快或过慢
4. 如果持续不准确，可以使用文字输入模式

### Q: 训练进度会丢失吗？

A: 不会。您的所有训练数据都保存在服务器上，换设备登录后可以继续。

### Q: 如何查看历史训练数据？

A: 进入"训练报告"页面，可以查看所有历史训练记录和能力变化趋势。

### Q: 建议每天训练多久？

A: 建议每天训练 15-30 分钟，保持规律性比单次长时间训练更有效。
