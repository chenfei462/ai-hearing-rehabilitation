## 演示流程

### 第一幕：登录与首页（1 分钟）

1. 打开应用首页
2. 点击"登录"，输入手机号 `13800000001`，验证码 `1234`
3. 展示首页四大功能入口卡片
4. **要点说明**: 老年友好设计（大字体 ≥18px、大按钮 ≥48px）

### 第二幕：听觉训练（3 分钟）

1. 点击"听觉训练"进入训练页
2. 选择"音节级"训练，点击"开始训练"
3. 播放题目音频，演示答题过程
4. 展示自适应升降级机制（连续答对/答错后的难度变化）
5. 结束训练，展示训练结果（正确率、用时）
6. **要点说明**: IRT 自适应引擎，根据能力参数动态选题

### 第三幕：对话陪练（3 分钟）

1. 返回首页，点击"对话陪练"
2. 选择"餐厅点餐"场景
3. 播放 AI 开场白语音
4. 演示语音输入 → ASR 识别 → AI 回复 → TTS 播放的完整流程
5. 展示多轮对话上下文维护
6. **要点说明**: ASR < 500ms，对话响应 < 3s

### 第四幕：发音反馈（3 分钟）

1. 返回首页，点击"发音反馈"
2. 获取发音练习任务
3. 播放标准发音示范
4. 录音并提交发音
5. 展示音素级评分结果（准确度、流利度、完整度）
6. 展示纠正建议和对比播放
7. **要点说明**: 发音评分 < 2s，DTW 音素对齐算法

### 第五幕：训练报告（2 分钟）

1. 返回首页，点击"训练报告"
2. 展示训练概览（总训练次数、正确率趋势）
3. 展示各级别能力分布
4. 展示每日训练活动热力图
5. **要点说明**: 数据驱动的康复进度追踪

### 第六幕：技术亮点（2 分钟）

1. 打开 API 文档 (`/docs`)，展示自动生成的接口文档
2. 访问 `/api/metrics`，展示实时监控指标
3. 展示响应头中的 `X-Process-Time`（性能监控）
4. **要点说明**: Serverless 架构、自动伸缩、全链路监控

## 常见问题应对

### Q: AI 服务响应慢怎么办？
A: 准备好离线降级方案：
- ASR 失败 → 提示"语音识别暂时不可用，请重试"
- TTS 失败 → 回退到 Web Speech API 本地播报
- LLM 失败 → 返回预设话术

### Q: 网络不稳定怎么办？
A: 展示弱网优化特性：
- GZIP 压缩减少传输量
- 响应缓存减少重复请求
- 前端代码分割减少首屏加载

### Q: 评委问到技术架构怎么办？
A: 准备以下要点：
- 前端: Vite + React 18 + TypeScript + MUI + Tailwind CSS
- 后端: Python FastAPI + SQLAlchemy + Redis
- AI: 阿里云百炼（Fun-ASR + Qwen3-TTS + 通义千问）
- 部署: 阿里云函数计算 FC（Serverless）
- 数据库: RDS PostgreSQL + Redis
